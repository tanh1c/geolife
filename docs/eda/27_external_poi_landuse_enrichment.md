# Stage 07c — External POI / Land-Use Enrichment\n\n## Purpose\n\nStage 07b established a factorized mobility representation. Stage 07c adds external place context as a separate semantic axis.\n\nStage 07c does not infer occupation, employment status, true WORK, or OFFICE.\n\n## Primary population\n\nStart from the support-qualified users with HIGH/MEDIUM HOME consensus.\n\nFor each such user:\n\n1. rebuild the same frozen 200 m behavior locations from private stay caches;\n2. exclude the supported HOME location;\n3. retain recurring non-HOME locations using the existing Stage-03a recurrence definition: stay_count >= 2;\n4. annotate mobility geometry from Stage 07b, Stage 05b, and Stage 06;\n5. query nearby OpenStreetMap semantic objects.\n\nThis avoids enriching all 182 users indiscriminately and keeps HOME exclusion explicit.\n\n## External source\n\nUse OpenStreetMap Overpass queries only.\n\nNo reverse-geocoded addresses are required.\n\nQueries are batched, sequential, cached privately, and use a configurable endpoint and User-Agent.\n\nRaw OSM responses, coordinates, object IDs, object names, and user-level mappings stay private.\n\nCommitted/reportable outputs are aggregate only.\n\n## Query radii\n\nPrimary semantic radius: 100 m.\n\nSensitivity radius: 250 m.\n\nThe maximum 250 m radius is queried once; the same returned objects are then re-aggregated at both radii.\n\n## Coarse non-exclusive context categories\n\n- residential\n- office_commercial\n- education\n- healthcare\n- industrial\n- retail_service\n- transport\n- civic_institutional\n- recreation_tourism\n\nAn OSM object may map to multiple categories.\n\nAn anchor may also have multiple categories within a radius.\n\nUnknown means no queried semantic category was found within the radius. It does not mean the real-world category is absent.\n\n## Coarse compatibility composite\n\nFor diagnostic comparison only, work_compatible_context means at least one of:\n\n- office_commercial\n- education\n- healthcare\n- industrial\n- retail_service\n- transport\n- civic_institutional.\n\nThis is intentionally broad. It is not a WORK label.\n\nResidential and recreation/tourism remain separate axes.\n\n## Primary analyses\n\n1. OSM semantic coverage at 100 m and 250 m.\n2. Category prevalence for all candidate anchors.\n3. Category prevalence stratified by stable-secondary, repeated-route-anchor, anchor-set and route-region geometry.\n4. Within-user stable-secondary vs other recurring non-HOME anchor comparison.\n5. Radius sensitivity.\n6. Context-signature distribution.\n\n## Privacy and interpretation boundary\n\nPrecise coordinates are needed internally to query external context, but they must never be committed or printed in aggregate reports.\n\nOSM coverage is incomplete and historically mutable. Missing tags are missing evidence, not negative evidence.\n\nExternal context may strengthen or weaken compatibility with a work-like interpretation, but it cannot reveal a user's job title.\n\n## Decision gate\n\nIf external category coverage is adequate and stable-secondary / route-related candidate geometry shows interpretable external convergence beyond same-user peers, preserve OSM context as an independent semantic axis.\n\nIf coverage is poor or context is mostly mixed/unknown, do not force semantic labels. Keep Stage-07b mobility profiles as the final supported representation.\n
